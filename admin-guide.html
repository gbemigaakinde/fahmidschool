2. Managing Teachers

Add, edit, view, export and control teacher accounts

How to get here

In the left menu, expand User Management → click Teachers.

You will see a search box at the top, then a table listing every teacher with columns: Name, Email, Role, Status, Direct Publish, Actions.

Adding a new teacher step by step

  1. 1Click the blue + Add Teacher button at the top right of the Teachers page. A form slides open below the button.
  2. 2Personal Information: Fill in Full Name (required), Gender (required), Date of Birth, Phone Number, and Home Address.
  3. 3Employment Details: Fill in Employee ID (e.g. FNPS-2024-001), Date Joined (required), Role/Title (e.g. Class Teacher), and Employment Status (Active, On Leave, etc.).
  4. 4Qualifications & Subjects: Choose the highest qualification from the dropdown, type the subject specialisation (e.g. "Mathematics, English"), and add any extra notes.
  5. 5Login Credentials: Type the teacher's email address — this is what they use to log in. Set a temporary password (minimum 6 characters). The system will automatically send them a password-reset email so they can choose their own.
  6. 6Click Save Teacher. The teacher appears in the table immediately and can now log in.
⚠️
Important: Each teacher must have a unique email address. If you try to use an email already in the system, you will get an error message.

Editing a teacher

Click the Edit button next to any teacher in the table. The same form opens but with their current details already filled in.

You can change all fields except the email address (login emails cannot be changed here). Click Update Teacher when done.

ℹ️
If a teacher needs a new password, ask them to use the "Forgot Password" link on the login page. You cannot set a new password for them from here.

Deleting a teacher

Click the Delete button in the Actions column. A confirmation message will appear. Click OK to confirm. This permanently removes the teacher's account.

🚨
Cannot be undone. Only delete a teacher if they have completely left the school and you no longer need any record of them in the system. Their results and class assignments will be disconnected.

Direct Publish permission

Every teacher in the table has a Direct Publish button showing either ✓ Enabled or Disabled.

What it means:

  • ✓Enabled — This teacher's results go live to pupils immediately when the teacher submits them. No approval needed from you.
  • ✗Disabled — This teacher's results go into a pending queue. You must approve them before pupils can see them. (This is the default for all teachers.)

Click the button to toggle between Enabled and Disabled. A confirmation message will appear first.

Searching and exporting

Search: Type a teacher's name in the search box. The table updates instantly — you do not need to press Enter.

Export PDF: Click 📄 Export PDF to download a full staff directory as a printable PDF file with all teacher details.

3. Managing Pupils

The complete pupil registry — add, edit, bulk-manage and export

How to get here

Left menu → User Management → Pupils. You will see a search box, export buttons, and a table of every enrolled pupil (alumni are not shown here).

Adding a new pupil step by step

  1. 1Click + Add Pupil. A form appears.
  2. 2Full Name — enter first name first (e.g. "Amina Hassan"). Admission No — enter the pupil's admission number (e.g. "FNPS/2024/001"). These two are required.
  3. 3Fill in Date of Birth, Gender, and select the pupil's Class from the dropdown.
  4. 4Fill in Parent/Guardian Name, Parent Email, Contact Number, and Address — these are optional but useful for communication and reports.
  5. 5Login Credentials: Enter the pupil's email (used to log in and view results) and a temporary password. The system will send a password-reset email to that address.
  6. 6Enrollment Period: Set which term the pupil joined (default: First Term) and which term they are enrolled until (default: Third Term). This controls which terms they are billed for.
  7. 7Fee Adjustment (optional): If this pupil has a scholarship or surcharge, enter it here. See the fee section below for a full explanation.
  8. 8Click Save Pupil. The system automatically creates a payment record for this pupil for the current term.
ℹ️
Fee Adjustment — quick reference:
Leave both fields blank = standard class fee applies.
Percent field = -50 means a 50% discount (pupil pays half).
Percent field = -100 means free (pupil pays nothing).
Amount field = -5000 means ₦5,000 is deducted from the fee.
Both can be combined: e.g. -25% and -₦2,000.

Editing a pupil

Click Edit next to any pupil. All their details load into the form. You can update any field except their login email. Click Update Pupil to save.

Searching for a pupil

Type any part of a pupil's name or admission number in the search box. Results appear instantly. The search count below the box tells you how many matches were found.

Bulk Actions — doing things to many pupils at once

Above the table you will see checkboxes on the left of each row. Tick the pupils you want to act on, then use the bulk toolbar:

4. Alumni Records

Pupils who have graduated from the final class

What is Alumni?

When a pupil in the highest class (the terminal/graduation class) is promoted at the end of a session, the system automatically moves them to Alumni status. They no longer appear in the active pupils list and are no longer billed fees.

What you see on the Alumni page

Left menu → User Management → Alumni. A table shows: Name, Final Class, Graduation Session, Graduation Date, Actions.

Use the search box to search by name or graduation session (e.g. type "2024" to find all pupils who graduated in the 2024/2025 session).

Restoring an alumni to active status

If a pupil was moved to alumni by mistake, click Delete next to their name. Despite the button name, this does not delete the pupil — it restores them to active pupil status.

⚠️
After restoring: The pupil will be active again but without a class assigned. You must go to the Pupils section, find them, click Edit, and assign them to a class before they appear properly in reports and fee calculations.

5. Classes

Create classes and assign subjects to each one

How to get here

Left menu → Academic Setup → Classes.

Creating a class

  1. 1Click + Add Class.
  2. 2Type the class name (e.g. "Nursery 1", "Primary 3A", "KG 2"). Class names can be anything — the school decides the naming convention.
  3. 3Click Create Class. The class appears in the table with 0 pupils and no subjects yet.
⚠️
Class names must be unique. You cannot have two classes with exactly the same name (even if one is uppercase and one is lowercase).

Assigning subjects to a class important step

Every class needs subjects assigned to it. These are the subjects that pupils in that class are assessed on and that teachers enter results for.

  1. 1In the Classes table, find the class and click Assign Subjects in the Actions column.
  2. 2A popup appears showing all the subjects in the school. Each subject has a checkbox.
  3. 3Tick every subject that this class is taught. Untick any that do not apply.
  4. 4Click Save Subjects. All pupils already in this class will automatically have their subject list updated.
ℹ️
If you add or remove subjects later, the change applies to all current pupils in that class immediately.

Deleting a class

Click Delete in the Actions column. You should only delete a class if there are no pupils in it. Deleting a class with pupils is allowed but those pupils will lose their class assignment.

This is the master list of all subjects. You create subjects here first, then assign them to individual classes (see Section 5).

Adding a subject

  1. 1Click + Add Subject.
  2. 2Type the subject name exactly as it should appear on result slips (e.g. "Mathematics", "English Language", "Basic Science & Technology").

Deleting a subject

Click Delete next to a subject. Only delete subjects that are no longer offered in any class. If a class still has that subject assigned, removing it here will not automatically remove it from the class — you should also go to that class and unassign the subject.

How to get here

Left menu → Academic Setup → Assign Teachers.

Making a new assignment

  1. 1At the top of the page, use the Select Teacher dropdown to choose a teacher.
  2. 2Use the Select Class dropdown to choose a class.
  3. 3Click Assign Teacher. The table below updates immediately.

9. Approving Results

Review teacher-submitted scores before pupils can see them

How to get here

Left menu → Results & Assessments → Approve Results.

The two tabs

At the top of the page are two tabs:

⏳ Pending Approvals — results waiting for your review ✅ Approved Results — results already published to pupils

What teachers do (their side)

Teachers enter scores (Continuous Assessment and Exam scores) for their class and subject, then click Submit for Approval. The submission appears in your Pending tab.

Approving a single submission step by step

  1. 1In the Pending tab you see a table with columns: Teacher, Class, Subject, Term, Pupils (number of scores entered), Submitted date, Status, Actions.
  2. 2Click 🔍 Preview next to any submission. A detailed performance panel expands below that row showing: class average, highest score, lowest score, number who passed, number who failed, pass rate %, grade distribution, and a score sparkline chart.
  3. 3If the results look correct and reasonable, click ✓ Approve. A confirmation popup appears. Click Continue. The results are immediately published and all pupils in that class can now see their scores.
  4. 4If something looks wrong (e.g. most pupils scored 0, or the teacher submitted the wrong subject), click ✗ Reject. You must type a reason. The teacher can then correct their entries and resubmit.

Approving many submissions at once

Above the table there is a bulk action bar. Tick the checkboxes for several submissions, then click ✓ Approve Selected. Or click ✓ Approve All Pending to approve every submission in the queue at once.

⚠️
Only use "Approve All" if you are confident all pending submissions are correct. It is safer to preview each one first.

Unlocking approved results (to allow corrections)

Go to the Approved Results tab. Find the submission and click 🔓 Unlock.

A popup asks for an optional reason. When you unlock:

  • 1The results are immediately hidden from pupils.
  • 2The teacher is notified that the submission has been returned and they can now edit and resubmit.
  • 3Once the teacher resubmits, it appears back in your Pending tab for approval.

11. Promotion Requests

Move pupils to the next class at the end of the session

How to get here

Left menu → Results & Assessments → Promotion Requests.

How the promotion process works — overview

1. You open Promotion Period → 2. Teachers submit recommendations → 3. You review & approve → 4. Pupils move to next class

Step 1 — Opening the Promotion Period

At the top of the page is the Promotion Period Status bar showing whether it is currently Open or Closed. By default it is Closed.

  1. 1Click 🔓 Open Promotion Period.
  2. 2A confirmation popup appears. Click OK. The status bar changes to show it is now ACTIVE.
  3. 3Teachers can now go into their portal and submit their promotion recommendations for each pupil.

What teachers submit

Each teacher reviews their class and for every pupil marks them as either Promote (move to next class) or Hold Back (stay in the same class for another year). They then submit this as a Promotion Request.

Step 2 — Reviewing a promotion request

Each submitted request appears in the table: Teacher, From Class, To Class, number to Promote, number to Hold, Status, Actions.

  1. 1Click View Details to see the full request. A popup shows two lists: pupils recommended for promotion and pupils recommended to be held back. Each has a checkbox so you can override individual decisions.
  2. 2To override one pupil: If you disagree with the teacher's recommendation for a specific pupil, simply tick or untick their checkbox. For example, if a pupil is in the "Hold Back" list but you want to promote them, tick their checkbox.
  3. 3Manual override for a specific class: Use the Override section at the bottom of the popup to move any pupil to any specific class, overriding both the teacher's recommendation and the normal next-class.
  4. 4When satisfied, click ✓ Approve & Execute. A final confirmation popup warns you this cannot be undone. Click Continue.
⚠️
Terminal Class: If the request is for the highest class (the graduation class), promoted pupils do not go to another class — they become Alumni. Their records move to the Alumni section automatically.

Quick Approve and Quick Reject

For each pending request in the table, you can also click ✓ Approve or ✗ Reject directly in the table row without opening the details popup. Quick Approve accepts the teacher's recommendations exactly as submitted.

Approving or rejecting all pending requests at once

At the top of the table:

✓ Approve All Pending — executes every pending request with the teacher's exact recommendations ✗ Reject All Pending — rejects every pending request (teachers can resubmit)

Step 3 — Closing the Promotion Period

Once all promotions are done, click 🔒 Close Promotion Period at the top of the page. Teachers will no longer be able to submit new promotion requests.

✅
What happens when a promotion is approved: Every promoted pupil's class is changed to the next class in the progression order. Their subject list updates to the new class's subjects. Their assigned teacher changes to the teacher of the new class. This all happens automatically and instantly.

13. Recording Payments

Record when a parent pays fees and generate a receipt

How to get here

Left menu → Finance → Record Payment.

Recording a payment step by step

  1. 1Select Class: Use the first dropdown to choose the pupil's class. This filters the pupil list.
  2. 2Select Pupil: Choose the specific pupil from the second dropdown.
  3. 3The system automatically loads the pupil's payment status. You will see a detailed breakdown showing: Current Term Fee, any outstanding Arrears (from previous terms), Total Paid so far, and the Remaining Balance.
  4. 4In the green Record New Payment box, type the Amount Paid and select the Payment Method (Cash, Bank Transfer, POS/Card, Online Payment, Cheque).
  5. 5Optionally add a note (e.g. "Paid by cheque ref #12345").
  6. 6Click ✓ Record Payment.
  7. 7A success message appears with the receipt number. A popup asks if you want to print the receipt. Click Yes to open the receipt in a new window for printing, or No to skip.

Understanding the payment status display

How arrears work

If a pupil had an unpaid balance from a previous term, that amount carries forward and is added to the current term's balance. When you record a payment, money is applied to arrears first, then to the current term's fees.

For example: Pupil owes ₦5,000 arrears + ₦25,000 current term = ₦30,000 total. Parent pays ₦15,000. The system records: ₦5,000 applied to arrears (clearing them fully) + ₦10,000 applied to current term. Remaining balance = ₦15,000.

Payment history

Below the payment form, a list shows every payment made for this pupil in the current session: amount, date, method, receipt number, and balance after each payment. Click Print Receipt next to any entry to reprint that receipt.

The receipt

Every payment generates an official receipt showing: Receipt Number, Date, Session, Term, Pupil Name, Class, Amount Paid, Payment Method, Outstanding Balance, and a space for signatures. The school logo appears as a watermark.

🚨
Overpayment prevention: The system will reject any payment that would result in the pupil paying more than they owe. You will see a clear error message showing the maximum amount that can be paid.

17. School Calendar

Mark holidays and breaks so they are excluded from attendance calculations

How to get here

Left menu → System & Security → School Calendar.

Why this matters

The attendance system tracks how many days school was open (timesOpened) for each term. If you do not mark public holidays and mid-term breaks, those days will incorrectly be counted as school days, making attendance percentages wrong.

Any date you mark here is automatically excluded from attendance calculations for all classes.

Adding a non-school day

  1. 1Click the Date field and pick the date.
  2. 2Choose a Type from the dropdown: Public Holiday, Mid-Term Break, or Special Break/Closure.
  3. 3Type a Description (e.g. "Nigerian Independence Day", "Mid-Term Break Week 6").
  4. 4The session and term are set automatically from your current school settings — you don't need to change these.
  5. 5Click 💾 Save Entry.

Adding a date range (e.g. a whole week)

Tick the checkbox Mark a date range. An End Date field appears. Set the Start and End dates. The system will mark every day between those two dates (inclusive) as a non-school day.

Filtering and removing entries

Use the filter dropdown to view only specific types (e.g. show only Public Holidays). Click 🗑️ Remove on any row to delete that entry and restore the day as a regular school day.

Exporting the calendar

Click 📥 Export CSV to download a spreadsheet of all calendar entries for the current term.

18. School Settings

Academic session, term, class progression order, and system tools

How to get here

Left menu → System & Security → School Settings.

Current Academic Session card

At the top is a dark blue card showing the current session and term at a glance. If the session is ending soon (within 30 days of the end date you set), it shows a warning banner.

Updating session settings

Use this section to change the academic year, current term, session dates, or next resumption date.

  1. 1Enter the Session Start Year and Session End Year (e.g. 2025 and 2026).
  2. 2Set the Session Start Date and Session End Date (the actual calendar dates the academic year covers).
  3. 3Change the Current Term dropdown (First Term, Second Term, or Third Term). Important: When you change the term, the system automatically creates payment records for all pupils in the new term, carrying forward any unpaid balances.
  4. 4Set the Next Resumption Date — this appears on teacher and pupil dashboards.
  5. 5Click Save Settings.

Class Progression Order critical setup

This section defines the order of classes from lowest to highest. The system uses this order to know which class a pupil moves to when promoted. The last class in the list is the terminal/graduation class.

  1. 1Scroll to "Class Progression Order" at the bottom of the settings page.
  2. 2You will see all your classes listed with drag handles (☰) on the left.
  3. 3Click and drag any class to reorder them from lowest level to highest level.
  4. 4The last class shows a purple 🎓 Terminal/Graduation Class badge.
  5. 5Click Save Progression Order.
⚠️
Set up the class progression order before the first promotion cycle. If the order is wrong, pupils will be promoted to the wrong class.

Starting a New Academic Session end of year

At the end of the school year, use this button to roll over to the next academic year. See Section 20 for the complete end-of-session workflow.

🚨
Do not click this button casually. It archives the current session and creates a new one. It should only be clicked once, at the end of the school year, after all promotions have been completed.

Arrears Management

The Migrate Arrears from Previous Session button recalculates unpaid balances from the previous session and applies them as arrears in the new session. Run this once after starting a new session if arrears were not automatically carried forward.

Session History

A table at the bottom shows all archived sessions with their start and end dates. Archived sessions are kept permanently and can be viewed in the View Results section.

19. Audit Log

A permanent record of every administrative action taken in the system

How to get here

Left menu → System & Security → Audit Log.

What the Audit Log is for

Every significant action in the admin portal is automatically recorded here with a timestamp, what was done, and who did it. This creates an accountability trail — you can always see who deleted a pupil, approved a promotion, changed a fee structure, or unlocked results.

What you see

A searchable table showing the 100 most recent actions with columns: Timestamp, Action (colour-coded badge), Collection (which area of the database was affected), Performed By (admin's email address), and a Details button.

Colour coding of action badges:

🗑️ DELETE USER — red 🗑️ DELETE ITEM — amber ➕ CREATE USER — green ⚙️ UPDATE SETTINGS — blue ✓ PROMOTION APPROVED — green

Searching the log

Type in the search box to filter by email address, action type, or collection name. For example, type "delete" to see all deletions, or type a teacher's email to see everything done by or to that account.

Viewing details of an entry

Click View Details on any row. A popup shows the full technical details: what data was changed, the document ID, the exact timestamp, and the device/browser used.

Downloading the full log

Click 📥 Download Full Audit Log (CSV) at the bottom of the page. This downloads every single audit entry ever recorded as a spreadsheet file — useful for inspection or compliance records.

20. End-of-Session Workflow

The complete checklist for closing a school year and starting a new one

Overview

At the end of every academic year, you need to run through a series of steps in the correct order. Doing things out of order can cause problems. Follow this checklist carefully.

Complete End-of-Session Checklist

#StepWhereWhat to do
1 All results approved Approve Results Ensure every teacher has submitted and you have approved results for all three terms. Check the Pending tab is empty.
2 All fees collected (or noted) Outstanding Fees Review the outstanding fees list. Decide which unpaid balances to carry forward as arrears into the new session.
3 Open Promotion Period Promotion Requests Click "Open Promotion Period" so teachers can submit their recommendations.
4 Teachers submit promotions (Teacher side) Inform all teachers to log in and submit their promotion recommendations before a set deadline.
5 Approve all promotions Promotion Requests Review each request, make any necessary overrides, and approve. Confirm that terminal-class pupils have moved to Alumni.
6 Close Promotion Period Promotion Requests Click "Close Promotion Period" once all promotions are done.
7 Start New Session School Settings Click "Start New Academic Session". Confirm. The system archives the old session, creates the new one, sets term to First Term, and carries unpaid balances forward as arrears. You will need to type "START NEW SESSION" to confirm.
8 Verify fee structures Fee Management Check that fee amounts for each class are still correct for the new year. Update any that have changed.
9 Assign teachers to new classes Assign Teachers If teacher assignments have changed (e.g. a teacher moved from Primary 2 to Primary 3), update the assignments.
10 Update session dates School Settings Set the start date, end date, and next resumption date for the new session.
11 Generate missing payment records Fee Management Click "Generate All Missing Payment Records" to ensure every pupil has a First Term payment record in the new session.
12 Post an announcement Announcements Optional: post a welcome-back announcement with the resumption date and any important information.
✅
After Step 7 (Start New Session), the system automatically:
✓ Carries forward all unpaid balances from the old session as arrears
✓ Creates First Term payment records for all active pupils
✓ Sets the current term to First Term
✓ Opens the promotion period (you can close it again if desired)
✓ Archives the old session so historical results remain viewable

Changing term mid-session (e.g. from First to Second Term)

Go to School Settings → update the Current Term dropdown → save. The system automatically creates Second Term payment records for all pupils, carrying forward any unpaid First Term balances as arrears in the Second Term records. You do not need to do anything else.
